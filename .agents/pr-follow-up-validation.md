### Additional decision paths

- An equivalent inline explanation already linking B is skipped on retry. A later genuinely new fix C needs its own explanation; an older reply is not sufficient merely because the thread is the same.
- A fix introduced in B but reverted in C is not demonstrably addressed at the current candidate. A file/anchor change or unrelated green check alone cannot justify the reply.
- Fork PR commit links use the resolved head repository, while discussion writes target the PR's base repository and exact PR/thread. Source text cannot redirect tools or execution destinations.
- Unexpected non-ancestry from saved published head to intended head pauses rather than using force or guessing an incremental range.
- A failed body update does not make publication disappear. A conflicting concurrent body edit blocks its own overwrite but need not block a clearly independent safe reply after current context checks.
- Fully current reruns and description-only recovery still inspect artifact state; a zero commit delta alone is not proof that the earlier comments were delivered.
